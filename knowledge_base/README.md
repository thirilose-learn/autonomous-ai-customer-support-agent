# Knowledge Base

This folder is reserved for custom fictional company policies and FAQ documentation to be authored in Level 4:
- Return Policy (`return_policy.md`)
- Refund Policy (`refund_policy.md`)
- Cancellation Policy (`cancellation_policy.md`)
- Shipping & Delivery Policy (`shipping_policy.md`)
- Warranty Policy (`warranty_policy.md`)
- Frequently Asked Questions (`faqs.md`)

These documents will be ingested by LlamaIndex and indexed into Supabase PostgreSQL (pgvector) in Level 4.
